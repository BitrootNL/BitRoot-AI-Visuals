# Bitroot Graph & Chart Guidelines

## Core Palette

Use these colors consistently across all graphs:

| Role | Color | Hex |
|--------|--------|--------|
| Primary Data Series | Cyan | #269FBA |
| Secondary Data Series | Purple | #5C78D9 |
| Tertiary / Supporting Series | Green | #A3D979 |
| Highlight / Special Attention | Beet | #B1325D |
| Success State | Green Success | #3DB873 |
| Warning State | Amber | #D4A843 |
| Error State | Red | #C94A3E |
| Information | Blue | #4D8FC9 |

---

| Element | Hex |

| Primary Text | #2D3333 |

---

## Recommended Series Order

For multi-series charts:

1. Cyan #269FBA
2. Purple #5C78D9
3. Green #A3D979
4. Beet #B1325D

Use semantic colors only for status information:

- Success → #3DB873
- Warning → #D4A843
- Error → #C94A3E

---

## Do

✅ Use Cyan as the primary data color.  
✅ Use Purple for secondary comparison series.  
✅ Use Green for positive outcomes, growth, or completion.  
✅ Use Beet sparingly to highlight a key data point or annotation.  
✅ Use `#2D3333` for axis labels, titles, and values.  
✅ Maintain WCAG AA contrast standards.

Source: Bitroot Design System. [1](https://qien-my.sharepoint.com/personal/selina_blijleven_code-cafe_nl/Documents/Microsoft%20Copilot%20Chat%20Files/DESIGN.md)

---

## Don't

❌ Use Green as the main chart color for every series.  
❌ Use Beet repeatedly across multiple series.  
❌ Use bright red `#E53935`, bright purple `#9C27B0`, or dark green `#1B5E20`.  
❌ Use Cyan, Purple, Green, and Beet at equal visual weight.  
❌ Place large colored backgrounds behind charts.

Source: Bitroot Design System. [1](https://qien-my.sharepoint.com/personal/selina_blijleven_code-cafe_nl/Documents/Microsoft%20Copilot%20Chat%20Files/DESIGN.md)
